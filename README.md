# AI Sales Monitor

Интерактивная CRM-демонстрация для мониторинга продаж: сделки, температура лидов, AI Risk, SLA, follow-up и рекомендации менеджеру отображаются в одном интерфейсе.

Проект работает в двух режимах:

- **Local Demo** — полностью автономная демонстрация на встроенных данных;
- **n8n Live** — загрузка и обновление сделок через собственный защищённый webhook.

## Возможности

- сводные показатели по воронке и потенциальной выручке;
- поиск по компании, Deal ID и менеджеру;
- оценка температуры и риска сделки;
- контроль SLA и ожидающих ответа клиентов;
- карточка сделки с перепиской и CRM-событиями;
- демонстрация сообщения клиента, ответа менеджера и нарушения SLA;
- запуск AI-анализа через n8n;
- автоматический fallback в Local Demo при недоступности интеграции.

## Быстрый запуск

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. По умолчанию используется Local Demo, поэтому ключи и внешние сервисы не нужны.

## Подключение n8n

Скопируйте локальный пример:

```bash
cp config.local.example.js config.local.js
```

Укажите в `config.local.js` адрес собственного webhook. Этот файл исключён из Git и автоматически подключается при локальном запуске.

Поддерживаемые события:

- `health_check`;
- `get_deals`;
- `new_client_message`;
- `manager_reply`;
- `sla_breach`;
- `change_stage`;
- `request_ai_analysis`.

### Требования безопасности

Не публикуйте адрес рабочего webhook, токены или клиентские данные. Production endpoint должен проверять авторизацию, ограничивать CORS, валидировать входные данные, применять rate limiting и возвращать только разрешённые поля.

